# Shape Shifter Curse — NeoForge Connector

Это переработанная версия неофициального порта Shape Shifter Curse для Minecraft 1.21.1 от [wuhenqiubai](https://github.com/wuhenqiubai/Shape-Shifter-Curse_Unofficial-Port), созданная для совместимости с **NeoForge 1.21.1 через Sinytra Connector**.

Исходный Fabric-порт тоже можно запустить на NeoForge через Connector, однако при наших проверках ряд важных механик не работал или работал неправильно. В этой ветке переработаны проблемные места: взаимодействие с жидкостями, влажность аксолотля, плавание, прыжки, скорость в воздухе и критические удары. Цель — приблизить поведение этих механик к оригинальному моду.

Хотя мод собран в **формате Fabric**, эта версия предназначена и проверяется для **NeoForge с Sinytra Connector**. Запуск напрямую на Fabric в этой ветке не поддерживается.

## Какую версию выбрать?

- **NeoForge 1.21.1:** выбирайте этот порт. Нужны Sinytra Connector, Forgified Fabric API и остальные зависимости из инструкции.
- **Fabric 1.21.1:** выбирайте [порт wuhenqiubai](https://www.curseforge.com/minecraft/mc-mods/shape-shifter-curse-unofficial-port).

Не устанавливайте оба порта одновременно.

Оригинальный мод создан onixary, XuHaoNan и другими участниками. Перенос на Fabric 1.21.1 выполнен wuhenqiubai; переработка совместимости с NeoForge/Connector — Kirillich611.
